# HappySmile instant callback prototype

A clickable, two-screen prototype for a Product Manager case study: an AI voice callback assistant ("Moli") for a dental clinic group.

- Screen 1: the patient's journey, from enquiry to a callback within two minutes, or at a time they choose.
- Screen 2: what the clinic team sees afterwards (enquiry queue, schedule, insights).

All patient names, numbers and figures are illustrative sample data. The call is simulated. No real calls are placed and nothing is sent anywhere. The 30% booking baseline comes from the case brief.

## Files

- `index.html`: the whole prototype as one self-contained page (open it in a browser, or deploy this file).
- `App.tsx` and `style.css`: the React and CSS source it was built from.

## Design intent (not a live system)

Moli says she is a virtual assistant, hands over to a person when asked, when pain is severe, or when she cannot answer, and holds the slot if nobody is free. Booking without staff would need access to each clinic's live calendar.
